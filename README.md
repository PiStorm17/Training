# Edinburgh 2027 training log

An offline web app: the 30-week Edinburgh Marathon plan plus a log for runs, the physio routine,
morning check-ins and weekly reports. No accounts, no server. Everything you log stays in this
browser on your phone, so export a backup from the Data tab every week.

Host it with GitHub Pages (Settings > Pages > Deploy from a branch > main / root), open the
site in Chrome on Android, then use the Chrome menu > Install app.
